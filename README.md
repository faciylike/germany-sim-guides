## 频段、APN设置与设备兼容性

　　这点太重要了！特别是从国内带手机来的朋友。

　　德国的4G/LTE主要使用频段**3（1800MHz）、7（2600MHz）、20（800MHz）**。这个800MHz是覆盖郊区和室内的关键。如果你的手机缺少Band 20，可能在屋里就只剩一格信号。

　　5G方面，主流是**n1、n78**。2025年的新手机基本都没问题，但一些老旧机型可能不支持。

**APN设置**：多数情况下插卡即用。但如果上不了网，别慌！手动设置一下就好：APN名称填“internet”或“web.”（不同运营商略有差异），其他字段留空即可。这个简单的小操作能解决90%的上网故障。

　　设备兼容性提醒：国内的一些定制安卓机或非常老旧的手机，可能会频段支持不全，最好提前查一下。iPhone用户通常无需担心。

## 实名注册（Postident）与合规指南

　　自欧盟法规生效以来，在德国购买SIM卡（包括预付费）都必须进行实名验证。这不是运营商的要求，是法律规定的。

　　过程其实不复杂：你在线下单后，运营商会要求你完成“Postident”验证。你需要：
1.  带着你的护照/居留证。
2.  去一家指定的邮局（Deutsche Post）或带有Postident服务的网点。
3.  工作人员核对你的身份信息和订单号，完成后即可激活卡片。

　　听起来有点麻烦？但为了安全和个人信息保护，这一步省不掉。想象一下如果谁都可以匿名用卡，那诈骗短信得多到啥程度。
